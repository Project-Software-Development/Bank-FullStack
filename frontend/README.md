# Frontend Banco Digital

Aplicação React + TypeScript da tela de cadastro.

## Configuração

1. Copie `.env.example` para `.env`.
2. Ajuste a URL da API:

```bash
VITE_API_BASE_URL=http://localhost:3000
```

## Execução

```bash
npm install
npm run dev
```

## Scripts úteis

```bash
npm run lint
npm run build
```
